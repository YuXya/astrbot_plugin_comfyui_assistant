# 0.1.0 测试状态

验收日期：2026-09-09。测试环境为 Windows、Python 3.12、AstrBot 4.28.0 和本机 ComfyUI。

## 自动化

34 项 Python 测试与 Ruff 检查通过，覆盖：

- LLM 结束后继续后台生成与发送，正常成功任务只有开始提示与最终图片两次发送。
- 宿主返回 False、明确拒绝、异常、超时；生成和发送分别记录，重发不增加生成次数。
- 重复查询、重复提交去重、重启恢复、提交未确认、发送中重启。
- 当前会话与发起人隔离，包括任务媒体引用和直接文件路径。
- 尺寸成对校验、尺寸范围、参数保持、图片数组占位符与 URL 混用顺序。
- 当前消息、引用消息、QQ 工具在当前 Agent 上下文中注入的图片。
- 宿主工具类型、回复抑制、插件加载与卸载。

管理页在 1500px 桌面和 390px 手机宽度完成浏览器测试，使用接口替身验证上传、删除、编辑、设置保存、重发及页面无横向溢出。页面不展示任务图片预览。

## 本机验证

使用新建几何图形和普通静物描述，对文生图、单图编辑、多图编辑分别测试默认 1024×1024、横图 1024×768、竖图 768×1024，共 9 次执行通过。

仅检查任务执行、输出文件和实际尺寸，没有目视检查画面效果。提交图与模板逐项比对，除指定输入、尺寸和随机种子外，模型、LoRA、扩写和采样参数保持不变。

真实 AstrBot 4.28.0 已验证插件安装、重载、四个工具注册、Plugin Pages 打开、设置与工作流说明保存。浏览器自动控制未完成真实 Plugin Pages 的文件选择，因此上传处理仅计入替身测试。

## 尚未验收

- 真实 QQ 收图、两条消息表现和用户发起的重发，仍需要在自己的测试会话验证。
- 流式回复和同轮混合其他业务工具的实际 QQ 行为。
